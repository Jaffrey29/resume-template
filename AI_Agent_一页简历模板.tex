\sectiontitle{项目经历}
\entry{AI Agent 用户抽奖与激励平台}{用户增长与激励系统}{2026.05--2026.08}
\textbf{技术栈：}Spring Boot、Spring Cloud Alibaba、RabbitMQ、Redis、Canal、XXL-JOB、Vue\par
\begin{itemize}
  \item \textbf{项目描述：}为智能体平台打造用户增长与激励系统，引导用户参与 AI Agent 体验，实现用户拉新、留存与促活。包含抽奖、活动、奖品、积分模块，支持抽奖、积分、兑换、返利等服务，以及黑名单校验、N 消耗积分指定抽奖范围、抽奖 N 次解锁奖品等玩法。
  \item 使用模板方法定义抽奖流程标准，调用责任链完成抽奖前过滤与抽奖；将抽奖中、后的动作抽象为组合模式规则树，实现业务规则动态编排。
  \item 采用 Redis \texttt{DECR} 分段消费与加锁兜底扣减奖品库存，消费成功后通过异步队列配合定时任务回写数据库，在避免超卖的同时降低数据库压力。
  \item 使用 RabbitMQ 解耦抽奖发奖、异步行为返利和库存更新流程；构建定时任务异步补偿机制，通过 MQ 重发失败任务，并结合业务唯一键完成幂等校验。
  \item 使用 OpenFeign、Nacos 与 XXL-JOB 支撑分布式架构；通过 Canal 同步分库分表产生的 Binlog 日志至 Elasticsearch，支持聚合查询。
\end{itemize}
